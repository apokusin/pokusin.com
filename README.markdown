# [pokusin.com](https://pokusin.com)

Served on Cloudflare Pages (`pokusin-com`), with automatic deployments from `master`.

The static countdown archive is generated by `python3 countdowns/generate.py`. Its royal archive and control room themes share a tiny Pages Function and D1 store for the next-countdown button. See [AGENTS.md](AGENTS.md) for local preview and editing instructions.
