# Not Yet Ripe — authored replacement candidate

The pinned Blender4.5.14 source creates an actual tapered gnarled branch, scars and
layered cambium, four unequal longitudinal cut specimens, opaque pith, relief
flesh/membranes/seeds, attached cupped leaves, a separate broad reset specimen and
13 threaded cotton papers. Archive image centres are flat and blank in the model.
The live numeral skin follows the actual unequal pulp relief. Runtime loads the
genuine archive stills and all live clock/tally values.

`authoring/build_scene.py` exports `scene.glb` and the editable `scene.blend`.
`--mobile` exports the separate portrait rig, preserving each specimen's anatomy
at its actual scale. `--proofs` renders neutral/light/side inspection files.
`render_phone_clay.py` renders neutral clay from the exact exported phone model.
`bake_pulp_ao.py` bakes real local contact AO separately from sunlight and albedo.
`build_typography.py` records OFL font candidates against the source. Map families
are authored from deterministic microscopic fields, separate from macro shape;
albedo contains no direct light, archive stills, timer or scenery photograph.

This is a browser candidate, not art acceptance. The first frame must still be
compared to the reference, including bark specificity, pith/flesh moisture,
natural leaf silhouettes, cotton thickness, source hierarchy and mobile reading
scale. Mesh/export/source checks do not establish device frame rate, physical
touch behavior or acceptance of the source comparison.

Use Blender **4.5.14 LTS** from the repository root:

```sh
Blender --background --python countdowns/assets/concepts/not-yet-ripe/scene/authoring/build_scene.py -- --proofs
Blender --background --python countdowns/assets/concepts/not-yet-ripe/scene/authoring/build_scene.py -- --mobile
python3 docs/countdown-concepts/architecture/measure_assets.py
```

The desktop run retains authoring/scene.blend. The phone rig is reproducible
from the same source script’s separate mobile branch and exports scene-mobile.glb;
it does not claim a separately saved mobile .blend. Authoring uses Blender Z-up
and glTF’s Y-up conversion. The manifest records actual named cut-flesh skins,
leaf/paper rigs and all thirteen archive surfaces plus the real destinations.

Geometry/maps are authored in this project, with no new license declaration
here. Included Roboto Condensed and Bodoni Moda keep the adjacent OFL notices,
official Google Fonts URLs and hashes in typography/manifest.json. The earlier
branch.webp is retained generated reference art, not the rebuilt branch volume
or a full scenery backdrop; ../provenance.json preserves its exact generation
prompt, output identifier and converted-file hash.

The shared asset-budgets.json records current desktop/portrait GLB bytes,
hashes, actual primitive attributes and base-level embedded RGBA8 image sizes.
It excludes separately loaded AO/thickness/ripeness masks, live ink/stills,
renderer targets and mipmaps. Its export counts do not establish a frame rate.
