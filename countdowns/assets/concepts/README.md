# Art layers

Each folder supplies only artwork or a procedural texture, never a reference mockup containing live UI. Clocks, counts, links and previews remain independent real elements. Wax and botanical `provenance.json` files record the exact generation prompt, returned original image filename, deployed WebP filename and **SHA-256 of that WebP**. The original filename identifies the ImageGen result; it is not a checksum of an original image retained here. Roadworks records its mineral scenery source. The drawing graphite texture and Fair's static ground plan are local vector textures/fallback art.

`crown.png` is a transparent generated brass crown, resized to 128 px for the fallback semantic discovery button. Brief: a tiny brass crown with uneven points, a softly brushed warm surface, and a simple silhouette, isolated on a transparent background without lettering. Successful 3D scenes render their own single physical crown and conceal this fallback image.
