### Motion choreography

Motion follows a hierarchy: main branch flex under 1°, twigs lag, leaf tips under 3°, papers first swing at their thread then flex at corners. Use 100–180 ms lag between botanical levels, rather than identical sine waves on every object. Focus stops selected-paper/neighborhood motion.

Confirmed reset sends an uneven green front along actual peel masks over about 1500 ms and briefly extends one existing branch tip by at most 8%, then returns. Flesh and screenshots stay unchanged. Decorative ripeness derives from the real deadline fraction of its preceding UTC calendar month; no independent stored progress. Existing 420 ms ticks and 1080 ms/45 ms stagger reset reels remain authoritative. Repeats start from current displayed colors/phase without accumulating growth. Remote updates cause only roughly 300 ms leaf response; failure never un-ripens. Preview opening freezes exact decorative phase.
